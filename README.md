# Medical Consultant Trainer Bot 🏥

Telegram-бот для тренировки навыков медицинских консультантов с использованием Groq AI.

## Возможности
- 🏥 5 реалистичных медицинских сценариев
- 🤖 Взаимодействие с виртуальными пациентами
- 📊 Детальный анализ коммуникации
- ⚡ Быстрые ответы благодаря Groq AI
- 🎯 Конкретные рекомендации по улучшению

## Установка
1. `pip install -r requirements.txt`
2. Создайте `.env` с токенами
3. `python main.py`

## Использование
1. Выберите медицинский сценарий
2. Проведите консультацию с пациентом
3. Получите профессиональный анализ
4. Улучшайте навыки на основе фидбека
