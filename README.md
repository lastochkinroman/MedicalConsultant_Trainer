# Medical Consultant Trainer Bot

> Telegram-бот для тренировки общения с пациентами

Практикуйтесь в медицинских консультациях с AI-пациентами. Получайте разбор разговора и советы, как общаться лучше.

## Что умеет

- 5 разных медицинских ситуаций для практики
- Пациенты отвечают как настоящие
- Анализирует, как вы общались
- Даёт конкретные советы по улучшению
- Работает быстро через Groq AI

## Установка

**1. Поставьте библиотеки:**
```bash
pip install -r requirements.txt
```

**2. Создайте `.env`:**
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GROQ_API_KEY=ваш_ключ_groq
```

Токены:
- Telegram — [@BotFather](https://t.me/botfather)
- Groq — [console.groq.com](https://console.groq.com)

**3. Запустите:**
```bash
python main.py
```

## Как пользоваться

1. Выберите сценарий (например, "пациент с головной болью")
2. Общайтесь с виртуальным пациентом
3. Завершите консультацию
4. Получите разбор: что было хорошо, что улучшить

Тренируйтесь сколько нужно — пациенты не устают.
